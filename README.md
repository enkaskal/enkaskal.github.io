# enkaskal.github.io
github pages hosting https://cryp7.net

## modular/remote themed
[enkaskal/jekyll-theme-chirpy](https://github.com/enkaskal/jekyll-theme-chirpy) is a fork of [cotes2020/jekyll-theme-chripy](https://github.com/cotes2020/jekyll-theme-chirpy) that enables [remote_theme](https://github.com/benbalter/jekyll-remote-theme) (if using default CDN js) or git based Gemfiles (if self hosting js) so that the site content itself is module/isolated and therefore doesn't have to have the upstream theme's license applied to it.
